## 0. 现状 vs 方案（三页映射）

| 方案页面 | 路由 | RN 现有实现 | 主要差距 |
|---------|------|-------------|----------|
| 设置页 | `/settings` | ✅ `app/tabs/settings.tsx`（外观/AI/数据/关于 分组）已有 | 主题为「深色模式 switch」而非「日/夜分段」，缺通知开关组、存储进度卡、导出/导入行、账号组 |
| 空状态页 | 嵌入 `/search` | ⚠️ 已有 `EmptyState` 组件 + 搜索页空态 | 方案要更丰富的「水墨插画+标题+副标题+让问墨语义搜索 CTA+多模式文案」；缺零笔记变体 CTA |
| 待办详情页 | `/todo/:id` | ❌ **无独立路由**；编辑在 `TodoListView` 底部弹窗（Modal）完成 | 需独立详情页：优先级三档选择器、提醒行、关联笔记行、完成为笔锋勾选、AI提炼确认条、删除确认、保存 |

> 结论：设置页基本成型（小幅补全）；空状态为增强；**待办详情页是主要新增**（从底部弹窗升级为独立页）。

## 1. 设置页（Settings）补齐

### 1.1 主题切换 → 日/夜分段（ThemeToggle）
- **现状**：`app/tabs/settings.tsx` 用 `Switch` 切「深色模式」。
- **目标**：改为**分段胶囊 `ThemeToggle`**：「日·水墨 / 夜·极光」，中间切换（复用 `useTheme` 的 `toggleTheme`/`mode`）。
- **新增** `src/components/settings/ThemeToggle.tsx`（日间：未选中宣纸灰底、选中焦墨黑底白字；夜间：未选中半透明白、选中极光渐变底深字）。

### 1.2 分组项补全
- **通知**：新增分组「通知」→ `CardRow`「待办提醒」+ `ToggleSwitch`（`notification.service` 已有权限逻辑，接系统通知开关）。
- **存储**：新增 `StorageCard` + `ProgressBar`（已用/总量进度条，`expo-file-system` 统计，`清理缓存` 动作）。
- **数据**：补「导出 / 导入」`CardRow`（跳转导出面板，`expo-sharing` 导出 Markdown/文本）。
- **账号**：可选「账号与同步」组（当前本地模式，显示「本地模式 · 无需账号」占位行）。
- **关于**：版本号改为从常量读取；补「意见与反馈」行。

### 1.3 组件
- 新增 `src/components/settings/`: `CardRow.tsx`（图标+标题+副标题+右侧操作/箭头）、`ToggleSwitch.tsx`（30×17 朱砂/灰轨道 动画）、`ProgressBar.tsx`、`StorageCard.tsx`、`GroupTitle.tsx`、`ThemeToggle.tsx`。

## 2. 空状态页（Search 零结果增强）

### 2.1 增强空态
- **现状**：`src/components/common/EmptyState.tsx`（图标+标题+描述+可换按钮）；搜索页零结果已用。
- **目标**：新增**水墨风空态**（可复用到搜索零结果与零笔记）：
  - 插画 `EmptyIllustration`（朱砂弧线 + 放大镜 + 底部椭圆阴影，纯 RN 绘制，不引 SVG）。
  - 标题「未寻得墨迹」（思源宋体 900、18px）、副标题按模式变化：
    - 全文：「没有与「{query}」匹配的笔记，换个说法试试」
    - 标签：「没有「{tag}」标签的笔记」
    - AI：「未寻得相关笔记，基于通用知识为你回答」
  - CTA「让问墨语义搜索」（朱砂胶囊 + 金色✨，夜间极光渐变）→ 自动切到 AI 模式并搜索。
- **新增** `src/components/common/EmptySearch.tsx`（含插画+CTA，供 `/search` 用）；`app/search.tsx` 零结果分支接入，已有「无输入→历史」「无结果→空态」结构改造。

### 2.2 零笔记变体
- 手帖列表空态复用（`NoteListView` 已有 `EmptyState`），保持引导「点击 + 新建」。

## 3. 待办详情页（TodoDetail）— 主要新增

### 3.1 页面与路由
- **新增** `app/todo/[id].tsx`（详情编辑页；`id` 空=新建，与笔记合并思路一致）。
- `app/_layout.tsx` 注册 `Stack.Screen name="todo/[id]"`（modal）。
- 待办列表项点击 → `router.push('/todo/${id}')`；底部快速条「+」→ `/todo/new`（新建）。

### 3.2 结构（对齐方案）
```
TodoDetail
├── TodoHeader（返回 + 「待办详情/新建待办」 + 删除）
├── TodoCard
│   ├── CheckboxRow（22×22 笔锋勾选 + 标题输入，完成删除线）
│   ├── 描述区（多行输入，淡底圆角）
│   ├── PrioritySelector（普通/急·今天/加急；「急」→ 朱砂/极光粉急签）
│   ├── ReminderRow（提醒时间行 → 日期/时间选择，显示「今天 14:00」）
│   ├── LinkedNoteRow（关联笔记行 → 笔记选择器，跳转详情）
│   └── AIExtractBar（若 AI 提炼来源显示确认条）
└── SaveButton「保存待办」（朱砂全宽胶囊）
```

### 3.3 组件
- 复用：`TodoRow` 勾选动画（TodoListView 内）、`UrgentSeal`（急签）、`EmptyState`、`Icon`。
- 新增 `src/components/todo/`: `Checkbox.tsx`（笔锋勾 `brush`）、`DescriptionInput.tsx`、`PrioritySelector.tsx`、`ReminderRow.tsx`、`LinkedNoteRow.tsx`。

### 3.4 行为
- 优先级三档单选（普通=1/急=2/加急=3，映射现有 `TodoPriority`）。
- 完成切换：笔锋划勾 + 删除线（复用 `TodoListView` 逻辑）。
- 提醒：系统通知（`notification.service`）+ 时间选择。
- 关联笔记：笔记选择器（`searchNotes` 复用）。
- 删除：二次确认 + 删除（`todoStore.deleteTodo`）。
- 保存：`todoStore.createTodo`/`updateTodo` → 返回列表。

## 4. 全局/服务扩展（对齐 RN 现状）

方案里的 Web 概念映射到 RN：
| 方案 | RN 现状 | 处理 |
|------|---------|------|
| 主题 `day/night/auto` | `useTheme` + `ThemeProvider` | 已有；ThemeToggle 复用 |
| `settings` store | `settingsStore`（autoClassify/aiProvider等） | 补 notifications/theme 相关字段即可 |
| 待办 store | `todoStore`（已有 CRUD + 优先级 + note_id） | 复用，无需新增 |
| 存储统计 | 无 | 用 `expo-file-system` 计算附件目录大小（`getInfoAsync` 递归） |
| 通知 | `notification.service`（已依赖） | 复用 |
| 导出 | `expo-sharing` + `expo-file-system` | 生成文本/Markdown 临时文件并 `shareAsync` |

## 6. 风险与注意事项

1. **Web→RN**：Tailwind/React Router/Framer Motion 不可用，用 RN 内置 + `expo-file-system/expo-sharing/expo-notifications`。
2. 日期时间选择器若引 `@react-native-community/datetimepicker` 需 `expo install`（native 模块，Expo Go 已含）。
3. 存储统计递归遍历附件目录耗时可放入异步后台。
4. ~~待办详情页从「底部弹窗」改为「独立页」~~ ✅ 已完成，`todoStore` 已同步。
5. 无障碍：开关配 `accessibilityRole="switch"`/`accessibilityState`，删除操作二次确认。
