# note-demo UI 交互设计规范

## 1. 设计原则

### 1.1 设计理念

以 Notion 风格为基础，融合渐变与卡片设计，打造简洁、高效、美观的笔记体验。

### 1.2 核心原则

1. **简洁优先**：减少视觉噪音，内容为王
2. **一致性**：统一组件风格、间距、圆角、阴影
3. **可访问性**：对比度达标，支持大字体
4. **响应式**：适配手机和平板不同尺寸
5. **动效克制**：过渡动画简洁流畅

## 6. 交互流程设计

### 6.1 创建笔记流程

```
用户点击 ➕ 新建
    │
    ▼
选择创建方式:
├── 空白笔记 -> 进入编辑页
├── 语音笔记 -> 开始录音 -> 转文字 -> 进入编辑页
├── 拍照笔记 -> 拍照 -> OCR识别 -> 进入编辑页
└── 链接笔记 -> 粘贴链接 -> 抓取预览 -> 进入编辑页
    │
    ▼
编辑内容 -> 点击保存
    │
    ▼
AI 自动分类 + 打标签 (后台执行)
    │
    ▼
保存成功 -> 返回列表页 -> 显示新笔记
```


### 6.2 AI 对话流程

```
用户进入 AI 聊天页
    │
    ▼
输入消息 -> 点击发送
    │
    ▼
显示用户消息气泡
    │
    ▼
显示 AI 输入中... (打字动画)
    │
    ▼
流式接收 AI 回复 (逐字显示)
    │
    ▼
回复完成 -> 显示操作按钮 (复制/引用/点赞)
    │
    ▼
可选: 点击引用笔记 -> 跳转笔记详情
```

### 6.3 搜索流程

```
用户点击搜索图标
    │
    ▼
进入搜索页 -> 显示搜索历史
    │
    ▼
输入关键词 -> 实时联想建议
    │
    ▼
点击搜索 -> 显示结果列表
    │
    ▼
结果分类展示: 笔记/待办/链接/图片
    │
    ▼
点击结果 -> 跳转到对应内容
```

## 9. 空状态与加载状态

### 9.1 空状态设计

| 场景 | 图标 | 文案 | 操作按钮 |
|------|------|------|----------|
| 无笔记 | 📝 | 还没有笔记 | 新建笔记 |

|------|----------|

| 项目 | 要求 |
|------|------|
| 对比度 | 正文文字 >= 4.5:1 |
| 触控目标 | 最小 44x44px |
| 字体缩放 | 支持系统字体缩放 |
| 屏幕阅读 | 所有元素有可读标签 |
