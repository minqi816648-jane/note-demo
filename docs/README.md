## 四、后续开发计划

以下为「整理后」的推进方向（具体以 `09-开发任务清单.md` 各阶段标注为准）：

1. **验收回归**：真机开发构建下核对 系统通知提醒 / 日期选择 / 导出分享 的原生能力（Expo Go 无法验证项）。
2. **功能补全**：导入功能（当前仅导出）、链接库分类改为标签后的详情页统一标签管理、待办重复提醒校验。
3. **体验优化**：信息 toast 主题化（统一样式）、列表卡片按压反馈、页面转场、无障碍（`prefers-reduced-motion` 动效降级）核对。
4. **性能**：极光光斑 GPU 降级、长卷/瀑布流滚动优化、图片懒加载。
5. **收尾**：文档与设计手册同步（含本索引）、最终双主题 QA。
