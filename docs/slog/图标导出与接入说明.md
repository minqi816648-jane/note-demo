## 二、统一设计规范（所有格式一致）

| 项 | 值 |
|----|-----|
| 网格 | 24 × 24 viewBox |
| 描边 | 1.75px 线性（stroke） |
| 端帽 / 连接 | `round` linecap / linejoin |
| 日间 | 焦墨 `#1C1B18`（常规）· 朱砂 `#B83A2A`（强调）|
| 夜间 | 雾白 `#F2F4FF`（常规）· 极光青 `#8FE7F5`（强调）|
| 换肤方式 | **`color` 继承**（stroke:currentColor），非逐图标配色 |
| 实心例外 | `i-more`(···) 用 `fill:currentColor`（`filled` 图标）|

强调色建议用主题令牌驱动（日 `--acc`, 夜 `--acc`），选中/焦点/hover 统一走令牌。

## 三、方式 A：SVG Sprite（`<use>` 引用）

适合无构建工具 / 原生 HTML / 多端共用一份定义。

```html
<!-- 1. 引入 sprite（一次） -->
<svg width="0" height="0" style="position:absolute"><symbol id="i-note" …/></svg>
<!-- 或外链： -->
<svg style="display:none"><use href="/assets/note-demo-icons.svg#i-note"/></svg>
```

```html
<!-- 2. 使用 -->
<svg class="note-icon" width="24" height="24"><use href="#i-note"/></svg>
```

```css
.note-icon{fill:none;stroke:currentColor;stroke-width:1.75;
  stroke-linecap:round;stroke-linejoin:round}
/* 换肤：父级控制 color 即可
   白天 color:#1C1B18；夜间 color:#F2F4FF；选中 color:#B83A2A / #8FE7F5 */
```

> 注意外链 `use href="*.svg#id"` 在部分旧浏览器（IE/Safari<12）不支持，低端机建议**内联 sprite**。

## 四、方式 B：React 图标组件（`NoteIcon.tsx`）

适合 React/Vue 工程，零手工、类型安全。

```tsx
import NoteIcon from './NoteIcon';

<NoteIcon name="note" size={24} />          {/* 常规 */}
<NoteIcon name="search" size={18} className="toolbar-ic" />
<NoteIcon name="more" filled title="更多菜单" />  {/* 实心图标传 filled */}
```

- `name` 类型由 `NoteIconName` 字面量收窄（43 个合法名，书写炸错即时报 TS 错误）。
- 通过父级 `color` 继承主题；`filled` 仅 `i-more` 需要。
- 无障碍：可传 `title`，自动带上 `aria-label` 与 `role=img`。

**Vue 版本**：若团队用 Vue，可用 `icons.json` 一键生成同构的 `icon-registry.js` 模板。

## 五、方式 C：JSON 注册表（`icons.json`）

适合：自动生成组件、图标挑选器、后端返回分类映射、国际化对照。

```jsonc
{
  "schema": "note-demo icon set v1",
  "count": 43,
  "designSpec": { "grid": 24, "strokeWidth": 1.75, "fill": "none", "linecap": "round", "linejoin": "round",
    "colors": { "day": {"ink":"#1C1B18","accent":"#B83A2A"},
                "night":{"ink":"#F2F4FF","accent":"#8FE7F5"} } },
  "categories": { "nav":"bottom-nav", "tool":"action", "view":"view-switch",
                  "cat":"category-tag", "media":"media", "edit":"editor-state", "set":"settings" },
  "icons": [
    { "id":"i-note", "name":"手帖", "category":"nav", "usage":"底部导航·笔记列表（首页）",
      "viewBox":"0 0 24 24", "body":"<path d=\"...\"/><path d=\"...\"/>" },
    // …共 43 条
  ]
}
```

示例：将 `body` 字符串内联为 HTML/JSX：

```js
// React
<div dangerouslySetInnerHTML={{__html:`<svg …>${icon.body}</svg>`}} />
// 或模板字符串拼 Vue v-html
```

## 六、接入建议（按项目实际情况选型）

1. **纯原生 / 多端** → 用 **SVG Sprite**（方式 A），入口注入一次。
2. **React 工程** → 用 **`NoteIcon.tsx`**（方式 B），如需 Tree-shaking 可改为按需 import 单枚组件。
3. **需要图标挑选 UI / 后端映射** → 用 **`icons.json`**（方式 C）。
4. 强调色、选中态统一走 CSS 变量，勿在组件内写死颜色，保证日/夜一键换肤。
5. 新增图标须符合规范（24 网格 / 1.75 描边 / round 端点），同步更新 sprite + 组件 + JSON 三份。

## 七、无障碍

- 装饰性图标：`aria-hidden="true"`。
- 功能性图标（搜索/排序/关闭/发送…）：加 `aria-label` 或 `title`。
- 尊重 `prefers-reduced-motion`（本图标集无动画，天然满足）。
