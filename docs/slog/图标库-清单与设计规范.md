## 三、统一设计规范（DESIGN SPEC）

| 参数 | 规范值 |
|------|--------|
| 网格 | **24 × 24** viewBox |
| 样式 | 线性（stroke outline）|
| 描边 | **1.75px** 统一全局 |
| 端帽 / 连接 | `stroke-linecap:round` + `stroke-linejoin:round` |
| 几何 | 主元素居中、圆角端点、统一视觉重量 |
| 日间颜色 | 焦墨 `#1C1B18`（常规）｜ 朱砂 `#B83A2A`（强调/选中状态）|
| 夜间颜色 | 雾白 `#F2F4FF`（常规）｜ 极光青 `#8FE7F5`（强调/选中状态）|
| 填充型例外 | `i-more`(···) 用 `fill:currentColor` 实心点 |
| 尺寸用法 | 导航 24 / 工具栏 18 / 列表卡 20（按 24 网格等比）|

### 使用方式（SVG symbol）
```html
<svg class="i"><use href="#i-note"/></svg>
```
```css
.i{width:24px;height:24px;fill:none;stroke:currentColor;
   stroke-width:1.75;stroke-linecap:round;stroke-linejoin:round;display:block}
```
通过 `color` 继承主题：日间容器 `color:#1C1B18`、夜间 `color:#F2F4FF`；选中态 `color:朱砂/极光青` 即可整库换肤，**无需为每个图标单独配色**。

## 四、落地建议

1. **落为 React/Vue 图标组件**：逐一封装 `<Icon name="note"/>`，内部使用 `<symbol>` + `<use>` 或内联 path，统一 `stroke` 由 CSS 注入。
2. **强调色用 CSS 变量**（`--acc` 日朱砂 / 夜极光青），选中态、focus、hover 统一走令牌，不写死。
3. **`i-more` 单独处理**：因用 `fill:currentColor`，需在组件内标注 `filled` 类型。
4. **无障碍**：装饰性图标加 `aria-hidden`，功能性图标（搜索、排序、关闭）加 `aria-label`。
5. **新增图标**遵循本文档规范（24 网格 / 1.75 描边 / round 端点），保证全库一致性。
