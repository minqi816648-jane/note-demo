## 2. 完成记录（已实现 · 变更说明）

> 以下为本轮及此前历次迭代已落地并验证的变更，供后续维护对照。

### 2.1 动效补齐（P0 · 已完成）
- 新增可复用动效模块 `src/animations/index.ts`（基于 RN `Animated`，无额外依赖）：`useCardIn`（inkIn/bIn 入场+交错）、`useWave`（声波 eq）、`useSealPulse`（印章脉冲）、`useRippleRing`（光环扩散/双层涟漪，带 stagger）、`useOrbBreath`（光球呼吸）。
- 接入点：
  - 手帖/创作浮层印章脉冲：`app/tabs/index.tsx`、`src/components/create/CreationSheet.tsx`；
  - 卡片入场交错 + 语音声波律动：`src/components/note/NoteListView.tsx`；
  - 底部中央「+」光环扩散：`app/tabs/_layout.tsx`；
  - 待办勾选动画：`src/components/todo/TodoItem.tsx`（`TodoListView.tsx` 已有）。

### 2.2 长按「+」直达录音（已完成）
- 背景：`expo-av` 已废弃且 Expo Go 不含其原生模块，报 `Cannot find native module 'ExponentAV'`；已迁移至 `expo-audio`（SDK 57 原生支持，含 Expo Go）。
- 改动：`package.json`（expo-audio）、`app.json`( plugin)、`services/voice.service.ts`（权限/音频模式/持久化，改用 expo-audio API）、`src/hooks/useVoiceRecorder.ts`（改用 `useAudioRecorder`/`useAudioRecorderState`）。
- 长按链路：`app/tabs/_layout.tsx` 中央「+」新增 `onLongPress` → `PlusSheetContext.openRecording()` → `CreationSheet` 以 `initialState='recording'` 打开并自动开录（`PlusSheetContext.tsx` 新增 `openRecording`）。

### 2.3 AI 自动分类 `finalizeAsync / execAsync` 崩溃修复（已完成）
- 根因：contentless FTS5 的 `'delete'`+insert 维护语句在部分 Android 上触发 expo-sqlite 原生语句竞态。
- 改动：
  - `services/search.service.ts`：`searchNotes` 改统一 LIKE 检索；`syncFtsForNote` 改为空操作（幂等，保留调用点）；
  - `services/db/schema.ts`：移除 FTS 维护触发器（notes_ai/ad/au），数据库版本升至 **5**（v4/v5 迁移幂等 drop 触发器）；
  - `services/tag.service.ts`：`setNoteTags` 不再逐条刷 FTS（改由调用方统一 `syncFtsForNote` 一次）;
  - `services/note.service.ts`：`createNote` 建后显式 `syncFtsForNote` 兜底。

### 2.4 待确认页高频刷新修复（已完成）
- 根因：`useAsyncData` 依赖内联 fetcher 身份 → `load` 每次重建 → `useEffect` 循环触发(无限刷新)。
- 改动：`src/hooks/useAsyncData.ts` 用 `fetcherRef` + 仅挂载一次；`app/pending-classification.tsx` 改用稳定方法引用。

### 2.5 笔记排序生效（已完成）
- 根因：每日长卷 `groupNotesByDay` 恒定按 `updated_at` 分组，忽略所选排序。
- 改动：`src/utils/date.ts` `groupNotesByDay(items,{sortBy,sortOrder})` 跟随排序字段；`NoteListView` 传 `filter.sortBy/sortOrder`；`app/tabs/index.tsx` 提升排序偏好并共享给 `NotesGalleryView`（按时间排序）。

### 2.6 待确认页支持修改 AI 分类与标签（已完成）
- `app/pending-classification.tsx`：卡片内展开分类单选 + 标签多选/增删编辑器，保存后以修改结果 → `confirmNoteClassification` 确认。

### 2.7 分类编辑（已完成）
- 新增 `app/category/[id].tsx`（编辑/新建分类：名称、图标、颜色、删除），`app/_layout.tsx` 注册路由。
- 入口：`src/components/note/NoteFilterBar.tsx` 分类标签**长按**进入编辑；末尾「＋ 分类」新建。
