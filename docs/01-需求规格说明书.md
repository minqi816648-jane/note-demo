# note-demo 需求规格说明书

## 1. 项目概述

### 1.1 项目名称
**note-demo** — AI 智能笔记助手

### 1.2 项目定位
面向个人用户的 AI 智能笔记助手，支持多模态记录（文字/图片/语音/附件/链接），通过 AI 自动分类整理，并可与 AI 对话协作完成笔记管理和任务执行。

### 1.3 核心价值
- **省时**：AI 自动分类、打标签，免去手动整理
- **全能**：支持文字、图片、语音、附件、链接等多种格式
- **智能**：AI 对话理解笔记内容，支持问答、翻译、任务提取
- **私密**：本地优先存储，敏感笔记可不上传

### 1.4 目标用户
个人用户（学生、职场人士、知识工作者等）

### 1.5 支持平台
- **首发**：Android（支持平板适配）
- **后续**：iOS（规划中）

## 3. 用例描述

### 3.1 核心用例：创建笔记并 AI 分类

**参与者**：用户
**前置条件**：用户已打开 App
**流程**：
1. 用户点击"新建笔记"
2. 输入笔记内容（文字/图片/链接）
3. 点击"保存"按钮
4. 系统调用 AI 分类服务
5. AI 返回分类结果（分类、标签、摘要）
6. 系统展示分类结果供用户确认/修改
7. 用户确认后笔记保存成功
8. 系统返回笔记列表，新笔记出现在对应分类下

### 3.2 核心用例：AI 对话管理笔记

**参与者**：用户
**前置条件**：用户已进入 AI 对话界面
**流程**：
1. 用户输入问题（如"帮我总结上周的会议笔记"）
2. 系统调用 RAG 检索相关笔记
3. AI 基于检索结果回答
4. 用户可继续追问
5. 对话过程中 AI 可执行操作（创建待办、整理笔记）
6. 对话记录自动保存

### 3.3 核心用例：分享内容保存

**参与者**：用户
**前置条件**：用户在浏览器/微信等应用中
**流程**：
1. 用户选择分享 → 选择本 App
2. 系统打开"保存向导"
3. 向导展示内容预览（标题/摘要/图片）
4. 用户选择保存方式（笔记/待办/链接）
5. 用户可选择"发给 AI 处理"选项
6. 保存成功后返回成功提示

## 4. 非功能需求

### 4.1 性能需求
- 笔记列表加载时间：< 1秒
- 笔记保存时间：< 2秒（含 AI 分类）
- 本地搜索响应：< 500ms
- 语音转文字：实时（流式）
- App 冷启动：< 3秒

### 4.2 离线需求
- 完全离线可浏览、编辑已有笔记
- 离线可进行本地关键词搜索
- 联网时自动同步、启用 AI 功能
- AI 分类需要网络（可离线缓存判断逻辑）

### 4.3 安全需求
- 敏感笔记本地加密存储（SQLCipher）
- AI 调用不传递敏感笔记内容
- API Key 存储使用系统安全存储

### 4.4 兼容性
- Android 8.0+（API 26+）
- 支持屏幕尺寸：360dp - 800dp
- 支持横竖屏切换

## 5. 用户界面设计原则

### 5.1 视觉风格
- Notion 风格为基础（极简中性、留白多）
- 融合渐变/卡片设计元素
- 支持手动切换暗色模式
- 圆角卡片、柔和阴影

### 5.2 交互原则
- 一步操作原则：核心操作（保存笔记）不超过3步
- AI 操作可见：AI 正在处理时显示状态（loading 动画）
- 错误友好：AI 出错时给出可理解的错误信息
- 撤销支持：关键操作（删除/分类）支持撤销

### 5.3 布局
- 底部 TabBar：首页 / AI对话 / 新建 / 待办 / 设置
- 笔记列表支持多视图切换（列表/日历/图库）
- 长按弹出快捷操作菜单

## 6. 技术方案

### 6.1 客户端
- **框架**：React Native (Expo)
- **状态管理**：Zustand
- **本地数据库**：SQLite (expo-sqlite) + SQLCipher 加密
- **导航**：expo-router
- **富文本**：react-native-pell-rich-editor
- **UI 组件**：自定义 + react-native-paper

### 6.2 AI 服务
- **对话模型**：通义千问 / DeepSeek（可配置 API Key）
- **OCR**：百度 OCR / 腾讯 OCR
- **语音转文字**：讯飞实时语音
- **语义搜索**：本地向量化（BGE-M3）+ SQLite FTS5
- **图片理解**：通义千问-VL

### 6.3 后端（规划）
- **框架**：Node.js (Express/NestJS) 或 Python (FastAPI)
- **数据库**：PostgreSQL + Redis
- **对象存储**：MinIO / S3
- **认证**：JWT + 设备绑定
