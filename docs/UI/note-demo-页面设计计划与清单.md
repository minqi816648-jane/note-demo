## 二、P0 核心闭环（首期 · 优先级最高）

### 页面 01 · 笔记编辑器

- **定位**：创作浮层「展开」后的完整编辑场景，连接「记录→保存→浏览」闭环关键枢纽
- **触发入口**：
  - 创作浮层六宫格（文字/拍照·图片/链接/附件）
  - 笔记详情页「编辑」按钮
- **核心功能需求**：
  - 富文本工具栏（标题/加粗/列表/代码块/引用）
  - 多模态插入（图片/录音/附件/链接卡片）
  - 自动保存 + 草稿标记
  - 编辑中调用 AI（问墨）续写/润色
- **依赖组件**：六宫格图标、印章按钮、声波动画、配色令牌

### 页面 02 · 笔记详情页（只读）

- **定位**：内容消费主力场景，从「每日长卷卷卡」点击进入
- **触发入口**：每日长卷卷卡点击
- **核心功能需求**：
  - 完整多模态内容渲染（文/图/音/附件/链接）
  - AI 摘要栏 + 引用来源贴纸
  - 底部操作（编辑/分享/移动到分类/删除）
  - 与「编辑」无缝切换
- **依赖组件**：长卷卡、印章、引用贴纸、左侧滑操作浮层

### 页面 03 · 搜索页

- **定位**：从列表页头部搜索按钮进入的全屏检索
- **触发入口**：列表页头部搜索 icon
- **核心功能需求**：
  - 全文搜索 + 分类/时间筛选
  - 搜索历史、热词
  - AI 语义搜索切换（问墨）
  - 结果沿用「每日长卷/时间线」分组，关键词描金高亮
- **依赖组件**：pills 筛选、长卷卡、描金高亮(mk)、空状态

### 页面 04 · 设置页

- **定位**：TabBar 设置入口，承载主题与账号
- **触发入口**：TabBar「设置」
- **核心功能需求**：
  - 主题切换（跟随系统 / 手动锁定日·夜）——**核心新组件**
  - 账号与同步
  - 数据导出 / 导入
  - 通知、存储管理、关于与反馈
- **依赖组件**：开关(tgl)、分组卡片、主题预览缩略图、双色 Token

### 页面 05 · 空状态页（2 变体）

- **定位**：新用户首入 + 零搜索结果的首屏反馈
- **触发入口**：列表无数据 / 搜索无结果
- **核心功能需求**：
  - 零笔记：水墨插画（悬笔/空砚）+ CTA「写下第一笔」
  - 零结果：「未寻得墨迹」提示 + 建议（换词/清筛选/让AI找）
- **依赖组件**：印章、朱砂按钮、淡墨灰文案

### 页面 06 · 待办编辑/详情小卡片

- **定位**：待办创建后的详情与编辑
- **触发入口**：待办页点按待办项 / 创作浮层「待办」入口
- **核心功能需求**：
  - 设提醒时间、优先级
  - 关联笔记（「急」签 + 关联文档）
  - 完成态切换
- **依赖组件**：待办项、朱砂「急」签、AI提炼条

- **需求**：日/夜/跟随系统三选项并排缩略图 + 实时预览；切换保存列表滚动位置与视图

## 五、全页面共用的设计原则与注意事项

> 以下原则适用于所有页面，无论优先级，开发时统一遵守。

### 5.1 双主题一致性（最高优先级）

| 原则 | 说明 |
|------|------|
| **同骨架仅换肤** | 日/夜共用信息架构与手势，只改 Token（色彩/玻璃/阴影） |
| **朱砂印章跨主题保留** | 印章、朱砂红是品牌符号，夜间不替换为渐变 |
| **文字可读性** | 正文对比度 ≥4.5:1（WCAG AA）；夜间主角雾白 `#F2F4FF` |
| **渐变仅用于强调** | 夜间渐变只用于按钮/图标/FAB，不用在正文大范围 |
| **动效一一映射** | 日墨晕↔夜玻璃弹性；日研墨↔夜光球；位移/时长安一致 |

### 5.2 视觉层级（只靠字重与留白）

- 装饰性元素（印章/题跋）**唯一允许的装饰**，其余层级靠字重+留白区分
- 配色遵循 `标题13.5 / 摘要10.5 / 元数据9` 的层级节奏

### 5.3 交互一致性

- 弹层统一 `sheetUp` 0.55s；卡片入场统一 `inkIn/bIn` 交错
- 图标统一 2px 描边、round cap/join
- 所有带动效的新页面：**尊重 `prefers-reduced-motion`**，提供降级动画
- 按钮按压有 `scale(.98)` 反馈，无点击感视为交互缺陷

### 5.4 无障碍

- 所有图标按钮配 `accessibilityLabel`/`aria-label`
- 浮层打开时**焦点锁定**（trap focus），关闭时回到触发按钮
- 输入框明确 label 与 placeholder 语义

### 5.5 性能

- 夜间 `backdrop-filter` 低端机降级为 92% 不透明深色
- 极光背景光斑动效用 `transform/opacity` + `will-change`，避免 GPU 重排
- 大量卡片交错入场设置 `content-visibility` 或懒渲染
- 录音/转写用 WebWorker，不阻塞 UI 线程

### 5.6 组件复用优先

每个新页面先**复用已定稿组件**（在组件清单勾选），确认无法满足才新增。避免每页自建一套视觉。
