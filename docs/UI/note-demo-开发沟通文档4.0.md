## 二、设计语言与主题系统

### 2.1 双主题语言
- **日间 · 水墨 SUMI**：宣纸暖底、焦墨主字、朱砂印章强调、淡墨灰度。文化意象=水墨/题跋/印章/砚台。
- **夜间 · 极光 AURORA**：深空底、玻璃拟态卡片、雾白正文、青→紫→粉极光渐变、朱砂印章保留作品牌符号。

### 2.2 主题切换
- 入口在**设置页外观组底部**：日/夜**分段切换按钮**（药丸容器内「日·水墨」「夜·极光」两段，选中=深墨底/未选=灰底，圆角 99）。
- 夜间伴随三枚低透明度**极光光斑**（青 #4FD8EB / 紫 #8B7CFF / 粉 #FF7AD9，opacity 0.12–0.18）作为背景装饰，**必须垫底（z-index 底层）**，不遮挡正文/卡片。

### 2.3 Design Token（已写入实施方案，摘要）
```css
/* 日间 */ --pbg:#F6F1E6; --card:#FFFDF7; --pfg:#1C1B18;
          --acc:#B83A2A; --mut:#8A8272; --line:#E5DCC8; --gold:#E8C56A;
/* 夜间 */ --pbg:#0A0D1F; --glass:rgba(255,255,255,.07); --pfg:#F2F4FF;
          --grd:linear-gradient(120deg,#4FD8EB,#8B7CFF 55%,#FF7AD9);
          --mut:#96A0C6; --gline:rgba(255,255,255,.14);
```
关键映射：**焦墨文字→雾白、淡墨灰→夜灰、卡片白→玻璃、朱砂→极光（但印章保留朱砂）**。

## 三、色彩 · 字体 · 圆角 · 动效规范

### 3.1 色彩令牌
| 令牌 | 日间 | 夜间 | 用途 |
|------|------|------|------|
| --pbg 页面底 | #F6F1E6 | #0A0D1F | 页面背景 |
| --card 卡片 | #FFFDF7 | #1A2040 / rgba白7% | 卡片/浮层底 |
| --pfg 主文字 | #1C1B18 | #F2F4FF | 标题/正文 |
| --acc 强调 | #B83A2A | #8B7CFF（极光） | 按钮/选中/印章 |
| --mut 次级文字 | #8A8272 | #96A0C6 | 说明/元数据 |
| --line 分隔 | #E5DCC8 | rgba白14%→#4F5870 | 描边/分隔线 |
| 危险色 | #C0392B | #E5734E | 删除/警示 |

### 3.2 字体
| 用途 | 字体 | 字重 |
|------|------|------|
| 标题/印章/按钮文字 | **Noto Serif SC** | Black / ExtraBold / Bold |
| 正文/元数据 | **Noto Sans SC** | Regular / Medium / SemiBold |
| 印章书法字 | Ma Shan Zheng（马善政楷体） | — |
| 代码/等宽 | Noto Sans Mono | Regular |
| 数字/动态 | Unbounded / Inter | — |

- **标题用思源宋体 Black（900）**，正文默认思源宋 Regular，UI 标签/按钮用思源黑体。
- 正文段落 `line-height 1.5–1.6`，首行缩进按编辑场景控制。

### 3.3 圆角与层级
- 卡片圆角：12–13（正文卡片）/ 6–8（小缩略图）/ 24（sheet 浮层顶部）。
- 胶囊/药丸：圆角 99（分段控件、pills、FAB）。
- 阴影：卡片用**柔和投影**（低透明度，非硬边）；**浮起按钮/FAB 用描边+上凸**。

### 3.4 动效（Framer Motion 方向）
- 收缩栏 / 更多菜单：展开收起 200–260ms、ease-out、transform 友好。
- 日历**墨点密度**：无过渡（静态密度），今日选中淡入。
- Bottom Sheet：从底部上滑（`spring`/slide）。
- 语音/声波卡：`inkwave` 声波推进动画。
- **无障碍**：尊重系统 `prefers-reduced-motion`，降级为静态呈现（Onboarding 插画、AI 选区高亮等）。

## 四、页面级规格（按画布逐页说明）

### 4.0 通用页面骨架（所有编辑/内容页）
自上而下：**状态栏(44) → 页面头/工具栏 → 内容区 → 底部操作/TabBar**。状态栏含时间 `9:41` 居中顶部。

### 4.1 笔记编辑器（P1-UI·笔记编辑器-日间/夜间）
- **顶部「砚台」工具栏**（单行，y50 高40-46，白卡/深玻璃 + 圆角11）：见第六章结构。
- **最后编辑时间行**（工具栏下方 y96 左侧，时钟icon +「最后编辑 · 2 分钟前」相对时间，淡墨/夜灰）。
- 编辑区（宣纸底/深空）：标题(Serif Black 22-24) + 正文(Serif 14，1.6 行高)。
- **问墨 AI 浮钮**：选中正文文字时浮出于选区侧（焦墨底金星「问墨」/夜间极光紫底），点开扩展面板「续写 / 润色 / 翻译」。
- 底部操作：描边「放弃」+ 朱砂「完 成」，文字双居中。

### 4.2 日历视图（P7 日 / N7 夜）
- 月头卷轴「◀ 2026年8月 ▶」左右对称、月份居中。
- 星期行 + **6 周×7 格**月历；每格=日期数字 + **墨点密度簇**（0–5 枚墨点表笔记量，焦墨渐变 / 夜间极光光点）。
- **今日**格：日间=淡朱砂圆底+朱砂数字；夜间=深暖光底+亮金数字。
- 点日期展开**当日长卷**（3 张 scard：文字 / 语音声波 / 图片缩略，横向滚动，第3张半露表可滑动）。
- 底部 **TabBar**：手帖/问墨/中央+（凸起 FAB）/待办/设置。

### 4.3 图库视图（P8 日 / N8 夜）
- 头部右上角「列表/日历/图库」三段视图切换（图库选中）。
- 分类 pills：全部 / 图片 / 视频 / OCR 文档。
- 年月分组折叠「▾ 2026年8月 (12)」。
- **双栏瀑布流** 6 卡：大图打底、视频首帧+播放标记+时长、墨色抽象底（无图）、OCR角标、加载失败占位。卡片统一细描边、圆角12。

### 4.4 附件预览（P10 日 / N10 夜）
- 水墨标题栏：返回 + 文件名「评审会-排期表.pdf」+ 元数据「PDF·1.2MB·8页」+ 更多。
- **文档内置预览**：白底阅读区（标题/行项/状态签/页码），夜间**保持白底保阅读**，仅工具条换肤。
- 底部操作条：三张精致工具卡「另存 / 用其他App打开 / 复制链接」，各含浅底圆角图标+文字。

### 4.5 分享导出（P11 日 / N11 夜）
- **Bottom Sheet 半屏浮层** + 压暗背景。
- 浮层内容：拖拽条 + 朱砂「享」印章+标题 + 长图卡片预览 → 生成长图按钮 → **导出 PDF / 导出 Markdown** 两卡 → **生成分享链接 + 复制**。
- 去除了「系统分享六宫格」与「长图卡印章」（简化后）。
- 导出卡：图标+文字垂直居中，夜间玻璃化。

### 4.6 Onboarding 引导页（日 / 夜）
- 4 步流程（写一笔 → AI归类 → 问墨问答 → 开始使用），当前演示第2步「AI 已为你归类」。
- 水墨插画：纸篇 → 飞散分类标签（工作/笔记/收藏）+ 朱砂虚线飞线。
- **步骤墨点连线**：4 点横排 + 连线底，当前点朱砂描边白心。
- 底部「跳过」+ 印章式「下一步」。

## 五、通用组件规格

### 5.1 底部中央「+」FAB（TabBar）
- 位于底部 TabBar **几何正中央**，`40×40` `cornerRadius14`，向上凸出 15px（`y:-12`），容器 `clipsContent:false`。
- 日间：焦墨底 #1C1B18 + 宣纸白描边；夜间：极光紫底 #8B7CFF + 玻璃描边。
- 4 个 tab 对称显式定位（手帖 x12 / 问墨 x92 / 待办 x211 / 设置 x291，各 76×48）。

### 5.2 视图切换分段控件（列表/日历/图库）
- 容器 120×34 灰底（日 #DCD6C8 / 夜玻璃 #1A2040），三段 `layoutGrow` 等宽，各 30 高圆角99。
- 选中段：日=焦墨底+白图标、夜=极光紫底+深图标；未选中图标灰。

### 5.3 朱砂印章
- **一律用 `frame + text` + flexbox 双轴居中**，勿用 SVG `<text>`（会拆节点+裁剪）。
- 白底文字于朱砂底（日用于强调），印章在夜间**保留朱砂**作品牌。

### 5.4 三分段 / pills / 开关
- 分段控件、pills：圆角 99 胶囊。
- 开关（Switch）：`34×20` 圆角，开=朱砂/极光 + 白滑钮靠右，关=灰。

## 六、编辑器工具栏与多媒体卡片（最新变更）

### 6.1 砚台工具栏（单行统一图标）
最终单行结构（9 图标，全 `18×18`、统一 `1.5px` 描边、圆角端点、**单一焦墨 #1C1B18**，夜间雾白；仅「字体颜色」A 的色条用朱砂作功能指示）：

```
[T 字体] [B 加粗] [≡ 列表] [A 字体颜色] ‖ [图片] [录音] ‖ [附件·回形针] ‖ [链接·链环] ‖ [···更多]
```

布局分组：
- **格式区**：字体 / 加粗 / 列表 / 字体颜色
- ║ 竖分隔
- **媒体区**：图片 / 录音
- ║ 竖分隔
- **附件**（回形针 · 独立成组，表"上传本地文件"）
- ║ 竖分隔
- **链接**（链环 · 独立成组，表"粘贴外部链接"）
- **···更多**（靠右，打开更多菜单）

> 注意：「附件」与「链接」虽都属插入，但**按功能分开、用不同图标**；已去除「代码块」「引用」按钮与引用正文；工具栏已从两行合并为单行。

### 6.2 多媒体插入卡片（对照A–E）
| 类型 | 卡片结构 |
|------|----------|
| **图片** | 大图块 + 图签（标题/日期）+ 「图片 1 · 已插入」标记 |
| **链接** | favicon 圆标 + 网页标题 + 域名 + 「链接 1 · 已抓取标题」 |
| **录音** | 红色播放钮 + `inkwave` 声波 + 时长「00:32·已转写」+ 「录音 1 · 已转写文字」 |
| **附件PDF** | 朱砂 PDF 图标块 + 文件名 + 「1.2 MB · 8页 · 已上传」+ 「附件 1」 |
| **综合满载** | 缩略图 + 链接卡 + 语音卡 + PDF卡 + 「已插入：图片1·链接1·录音1·附件1」统计行 |

**排版要求（对照E经验）**：卡片间距统一 ≥16px、宽度统一（与正文左缘对齐 335）、缩略图不与其他卡紧贴；编辑区下方留白为可滚动区。

## 七、更多菜单「···」与三维度组织

### 7.1 菜单容器
- 从工具栏右上「···」下方展开，**右对齐**，白卡/深玻璃浮层，圆角12、细描边。
- 高度自适应内容，含分隔线分组。

### 7.2 菜单结构（三维度二级分类版，对照F）
```
历史版本
─────────────────
[文件夹 ▾]  ← 展开态，朱砂图标
     · 工作笔记     （缩进二级子项，朱砂点）
     · 学习摘录     （灰点）
[分类 ▸]     ← 四宫格图标，可展开
[标签 ▸]     ← 标签图标，可展开
─────────────────
不上传 AI 分析  [开关ON]   ← 浅朱砂底强调，盾牌图标
─────────────────
删除笔记    ← 红色警示
```

- **三个组织维度**：文件夹（容器，可展开套子项）、分类（四宫格，可展开）、标签（可展开）。
- 「不上传 AI 分析」为**隐私重点项**：浅朱砂底 `#FBF3EC` + 朱砂文字 + 开启态开关，视觉强调可一眼定位。
- 已去除「重命名」「导出笔记」两项。
- 后续点「分类/标签 ▸」应展开其二级子项（同文件夹展开态样式）。
