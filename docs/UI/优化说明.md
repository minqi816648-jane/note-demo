# 笔记列表页（手帖）优化说明

## 需求
优化笔记列表页设计，**保留**四大结构，色彩体系沿用《优化方案.md》不变。

## 保留的结构（未改动）
1. **状态栏** —— 时间 + 信号格 + 电池
2. **头部区域** —— 「手帖」标题 + 印章「记」+ 副标题「8月5日·今日已记3笔」+ 右侧 搜索钮 + 三段视图切换
3. **内容区（每日长卷）** —— **分类 pills（全部/工作/学习/生活，已去除收藏夹）+ 排序按钮（创建时间/标题）** + 日期题头（菱形节点）+ 横向滑动卷卡（scroll-snap）
4. **底部导航栏** —— 手帖 / 问墨 / 中央「+」创作入口 / 待办 / 设置

## 优化点（在结构与色值不变前提下提升质感与可用性）
- **双主题实时切换**：顶部日间/夜间开关，背景随主题切换，夜间附带极光光斑漂移动画与毛玻璃卡。
- **卡内容类型更丰富**：文字卡、语音卡（声波动画）、图片卡（缩略图）、链接卡（未读标记）四类齐备。
- **卷卡动效**：悬浮上浮 + 卡片入场「墨晕」动画。
- **交互可用**：分类筛选真实过滤（含空状态提示）、**排序自由切换（创建时间/标题，下拉展开）**、视图三段切换演示、中央「+」光环激活动画。
- **滚动层次**：内容区底部毛玻璃渐变，提示可继续浏览。
- 印章脉冲、TabBar 毛玻璃、滚动隐藏滚动条等细节均沿用原设计。
