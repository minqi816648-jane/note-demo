## 1. 项目概述

### 1.1 产品定位

note-demo 是一款 **AI驱动的智能笔记应用**，融合传统水墨美学与现代交互设计，支持多模态记录（文字/语音/图片/链接/附件/待办）和AI智能分类、问答。

### 1.2 核心决策（四大定稿）

| 决策项 | 定稿方向 | 说明 |
|--------|----------|------|
| **待办页** | 保留水墨SUMI原设计 | 今日三事题头、笔锋划勾、朱砂"急"签、AI提炼确认条全部沿用 |
| **主题双轨** | 极光AURORA转为夜间模式 | 与日间水墨共用同一套信息架构，跟随系统或手动切换 |
| **AI对话** | 水墨×纸间融合 | 关键词淡金高亮、引用出处贴纸、印章式行动按钮，注入编辑感 |
| **笔记列表** | 「每日长卷」+ 中央「+」 | 呈现布局保留每日长卷；「记一笔」统一收进底部导航中央「+」按钮 |

### 1.3 信息架构

```
┌─────────────────────────────────────────────┐
│               底部导航 TabBar                │
├──────────┬──────────┬────────┬──────────────┤
│  手帖     │   问墨    │   +    │    待办       │  设置  │
│ (笔记列表) │ (AI对话)  │(创作入口)│ (任务管理)    │        │
└──────────┴──────────┴────────┴──────────────┘
```

| 日间元素 | 夜间映射 | 备注 |

| 描金高亮 | 暖金光晕（降饱和度） | 防夜间刺眼 |
| 墨晕入场动画 | 玻璃弹性入场 | bIn关键帧 |
| 研墨loader | 青色光环呼吸 | orbP关键帧 |

- `overflow-x: auto; scroll-snap-type: x mandatory`

**单张卷卡（scard）**：
```

左侧装饰: 2.5px宽朱砂竖条（opacity .55）

│ [工作]  10:24         │ ← sm: 标签+时间
└──────────────────────┘
```

**卷卡内容类型**：

| 类型 | 展示方式 | 特殊元素 |
|------|----------|----------|
| 文字笔记 | 标题+摘要2行 | 分类标签+时间 |
| 语音笔记 | 标题+声波动画 | 时长+转写状态 |
| 图片笔记 | 缩略图(50×50)+标题 | 图片角标 |
| 链接笔记 | 标题+抓取摘要 | 链接图标+未读标记 |

**声波动画（inkwave/miniwave）**：
- 5-7根竖条，高度随机7-17px
- 动画：`eq` 1.1s ease-in-out infinite alternate（交错延迟0.12s）
- 颜色：焦墨黑（日）/ 渐变色（夜）

### 4.5 视图切换（三种布局）

虽然定稿为「每日长卷」，但保留了三种视图切换能力：

1. **列表视图**（默认）：时间线分组 + 双列卡片（n2row）
2. **日历视图**：按日历格展示，可延展为「按日翻卷」
3. **图库视图**：双栏瀑布流（masonry），适合图片较多的场景

### 4.6 空状态（ghost）

- 图标：4×4px圆点
- 文字：9.5px，灰色
- 引导文案：「还没有笔记，点击下方 + 开始记录」

## 5. 页面二：创作浮层（记一笔）

**浮层样式**：

- 阴影：`0 -16px 46px -12px rgba(24,21,16,.55)`

- 背景压暗层：`rgba(24,21,16,.44)`（日）/ `rgba(4,6,14,.55)`（夜）

### 5.3 三种状态详解

#### 状态一：初始态

**速记输入条（qrow）**：
- 胶囊形状 `border-radius: 999px`
- placeholder：「随手敲几个字，回车即保存…」
- 右侧图标：麦克风 + 发送箭头
- **交互**：直接输入文字后回车/点击发送 → 即时保存为文字笔记（最短路径1步）

**六宫格入口（grid6）**：

| 入口 | 图标 | 标题 | 副标题 | 特殊标记 |
|------|------|------|--------|----------|
| 文字 | 📝 note | 文字 | 富文本·代码块 | - |
| 拍照·图片 | 🖼 img | 拍照·图片 | AI识图·OCR | - |
| 语音 | 🎤 mic | 语音 | ≤10分钟转文字 | 「实时」角标 |
| 附件 | 📎 clip | 附件 | PDF·Word·txt | - |
| 链接 | 🔗 link | 链接 | 自动抓取预览 | - |
| 待办 | ✓ todoadd | 待办 | 提醒·优先级 | - |

每个宫格：
- 图标容器：33×33px，圆角11px
- 标题：10px，800字重
- 副标题：7.5px，灰色

**AI自动归类开关（swopt）**：
- 默认开启
- 虚线边框包裹
- Toggle开关：30×17px
- 文案：「保存后由问墨自动分类、打标签」

#### 状态二：录音态

```
┌─────────────────────────────────────┐
│ ═══════                             │
│ [🎤] 语音速记                        │
│ 实时转写中 · 完成后存为语音笔记        │
├─────────────────────────────────────┤
│                                     │
│         〇 〇 〇                      │ ← 双层涟漪(ringp动画)
│            ●                         │ ← 朱砂墨团82×82px
│          🎤                          │
│                                     │
│         0:12                         │ ← Fraunces 21px粗体
│       录 音 中                        │ ← 8px 字间距.34em
│                                     │
│ "…确认9月15号上线…|"                 │ ← 实时转写(rlive)
│                                     │
│   [✕放弃]  [✓完成]   [■停止]        │ ← 操作键(ract)
└─────────────────────────────────────┘
```

**录音控件规格**：
- 墨团：82×82px，径向渐变 `radial-gradient(#D14A35, #99291C 68%)`
- 涟漪：双层 `ringp` 动画，2s循环，错开0.6s
- 计时器：Fraunces字体，21px，700字重
- 状态文字：「录 音 中」，朱砂红色，字间距 `.34em`
- 实时转写区：最大宽度，9.5px行高1.8，带闪烁光标
- 操作按钮：
  - 放弃：40×40px，边框样式
  - 完成：54×54px，朱砂实心（主操作放大）
  - 停止：40×40px，边框样式

## 9. 动效规范

### 9.1 核心动画关键帧

```css
/* 墨晕入场 - 日间卡片入场 */
@keyframes inkIn {
  from { opacity: 0; filter: blur(7px); transform: translateY(10px); }
  to   { opacity: 1; filter: blur(0); transform: none; }
}
/* 时长: 0.7-0.85s | 曲线: cubic-bezier(.2,.8,.2,1) */

/* 玻璃弹性入场 - 夜间卡片入场 */
@keyframes bIn {
  from { opacity: 0; transform: translateY(14px) scale(.97); }
  to   { opacity: 1; transform: none; }
}
/* 时长: 0.7s | 曲线: cubic-bezier(.2,.9,.3,1.2) 带微过冲 */

/* 声波律动 */
@keyframes eq {
  from { transform: scaleY(.45); }
  to   { transform: scaleY(1.2); }
}
/* 时长: 1.1s | 缓动: ease-in-out infinite alternate */

/* 印章脉冲 */
@keyframes sealPulse {
  0%, 100% { transform: rotate(-4deg) scale(1); }
  50%      { transform: rotate(-2deg) scale(1.05); }
}
/* 时长: 5s | 缓动: ease-in-out infinite */

/* 光环扩散（FAB/录音涟漪） */
@keyframes ringp {
  0%   { transform: scale(.85); opacity: .9; }
  75%  { transform: scale(1.35); opacity: 0; }
  100% { opacity: 0; }
}
/* 时长: 2.2-2.4s | 缓动: ease-out infinite */

/* 笔锋划勾（待办完成） */
@keyframes brush {
  to { stroke-dashoffset: 0; }
}
/* 时长: 0.7s | 延迟: .5s | 缓动: ease forwards */

/* 极光漂移 - 夜间背景 */
@keyframes aur1 {
  from { transform: translate(0,0) scale(1); }
  to   { transform: translate(-34px,40px) scale(1.15); }
}
@keyframes aur2 {
  from { transform: translate(0,0) scale(1.1); }
  to   { transform: translate(40px,-30px) scale(.94); }
}
/* 时长: 11-15s | 缓动: ease-in-out infinite alternate */

/* 光球呼吸 - 夜间头像/ loader */
@keyframes orbP {
  0%, 100% { box-shadow: 0 0 12px rgba(139,124,255,.55); }
  50%      { box-shadow: 0 0 26px rgba(79,216,235,.95); }
}
/* 时长: 2.6s | 缓动: ease-in-out infinite */

/* 浮层滑入 */
@keyframes sheetUp {
  from { transform: translateY(44px); opacity: .25; }
  to   { transform: none; opacity: 1; }
}
/* 时长: 0.55s | 曲线: cubic-bezier(.2,.8,.2,1) */
```

## 11. 开发对接建议

### 11.1 技术栈建议

- **移动端**：React Native / Flutter
- **Web端**：React + TypeScript + Tailwind CSS
- **动画库**：react-native-reanimated / Framer Motion
- **状态管理**：Zustand / Redux Toolkit

### 11.2 设计Token沉淀

建议将以下内容沉淀为 Design Token：

1. **色彩令牌（Day/Night 双套）**
2. **圆半径令牌**：4级（small: 7px, medium: 12px, large: 16px, xlarge: 24px）
3. **阴影令牌**：4级（card / fab / stamp / overlay）
4. **间距令牌**：4px base grid
5. **字体令牌**：字号/字重/行高/字距
6. **动效曲线**：4条核心曲线
7. **动效时长**：9档（100ms - 1000ms）

### 11.3 组件拆分优先级

**P0 - 核心流程（必须首期实现）**：
1. TabBar 导航 + 中央「+」按钮
2. 笔记列表 - 每日长卷布局
3. 创作浮层 - 三态（初始/录音/AI确认）
4. AI对话页 - 基础问答

**P1 - 完整体验（次期实现）**：
5. 待办页 - 今日三事
6. 夜间模式完整适配
7. 左滑/长按手势
8. 视图切换（列表/日历/图库）

**P2 - 锦上添花（后期迭代）**：
9. 设置页
10. 空状态页
11. 编辑器页（富文本）
12. 日历视图完整版

### 11.4 性能注意事项

1. **夜间模式毛玻璃**：`backdrop-filter` 在低端机上需降级为 92% 不透明深色
2. **极光动画**：3个光斑同时漂移，注意 GPU 渲染性能
3. **列表动画**：大量卡片交错入场时使用 `will-change: transform, opacity`
4. **录音实时转写**：需 WebWorker 或原生线程处理，不阻塞UI
5. **scroll-snap**：iOS/Android 兼容性测试

### 11.15 无障碍（Accessibility）

1. 所有图标按钮需配 `aria-label` / `accessibilityLabel`
2. 色彩对比度：正文至少 4.5:1（WCAG AA）
3. 动画尊重 `prefers-reduced-motion`
4. 焦点管理：浮层打开时 trap focus
