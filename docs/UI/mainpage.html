01

设计系统 · 昼夜双主题

同一骨架 · 两套皮肤

日间与夜间共用同一套信息架构与手势，只换肤不换骨：日间取"宣纸 + 焦墨 + 朱砂"，夜间取"深空 + 极光玻璃"。所有标志性动效都有昼夜映射（墨晕 ↔ 极光漂移、研墨 ↔ 光球呼吸），保证用户在切换模式时零学习成本。

日间 · 水墨 SUMI

DAY MODE
宣纸为底、焦墨为文、朱砂点睛。装饰只出现在印章与题跋两处，层级靠字重与留白。
宣纸白 卡片白 焦墨黑 朱砂红 淡墨灰 淡金高亮

AURORA NIGHT

夜间模式
深空底色 + 流动极光光斑，界面元件为毛玻璃悬浮。渐变只用于强调元素，正文保持高可读。
深空黑 玻璃蓝 极光青 极光紫 极光粉 雾白
TYPE 字体
思源宋体 900 标题 · 马善政楷体用于印章字 · 思源黑体正文（行高 ≥1.7）；夜间数字与英文标签用 Unbounded。层级：标题 13.5 / 摘要 10.5 / 元数据 9。
MOTION 动效映射
日：墨晕入场 blur→实 / 研墨 loader / 笔锋划勾 / 印章按压回弹。夜：极光光斑 11–15s 漂移 / 光球呼吸辉光 / 弹性过冲入场。共用：左滑与勾选反馈的位移、时长一致（400–700ms ease-out）。
INTERACTION 交互
胶囊 FAB「记一笔」（日朱砂 / 夜渐变）· 列表/日历/图库三段视图切换 · 左滑浮出操作（日朱砂 / 夜霓虹）· 长按印章式环形菜单 · 待办页底部速记条常驻。

03

「+」创作浮层 · 记一笔的展开页

初始 / 录音 / AI 归类 三态

点按底部中央「+」，一滴墨自按钮洇开，半屏创作浮层承住全部新建动作：顶部速记输入条"想到什么敲什么"，回车即存为文字笔记；六宫格收口图片 / 语音 / 附件 / 链接 / 待办多模态入口；保存后按用例 3.1 进入 AI 归类确认，让"记录 → 分类"在一次浮层里完成。

初始态

  • 速记条顶部常驻输入，敲完直接存（F01），路径最短 1 步
  • 六宫格文字 / 拍照·图片（F08）/ 语音（F09）/ 附件（F11）/ 链接（F12、F35）/ 待办（F25），多模态一口收
  • AI 开关"保存后由问墨自动分类打标签"默认开启（F15），可关；敏感笔记可切"仅存本地"（F42）
  • 长按 +跳过浮层直达语音速记（F21 语音指令同入口）

录音态

  • 朱砂墨团呼吸 + 涟漪，录音状态一眼可辨
  • 实时转写语音流式转文字即时预览（F09），保存后音频可折叠展开
  • 三键放弃 / 完成 / 停止，间距加大防误触

AI 归类确认态（用例 3.1 映射）

  • 结果可见AI 返回的分类 / 标签 / 摘要全部可在确认前修改（步骤 4–6）
  • 确认归档点按确认后落库，新笔记出现在对应分类长卷中；误操作支持撤销
  • 待办分支若保存为待办，此态改为"设提醒 / 优先级"确认

04

AI 对话页 · 水墨 × 纸间融合

定稿 · 日间

骨架与人设保留水墨「问墨」：印章头像、墨色气泡、研墨 loader、朱砂发送键。从纸间方向引入四处编辑感元素——描金高亮标出答案关键词、引用贴纸可溯源、印章式行动按钮让 AI 的建议一键落地、快捷指令做成纸签样式。

水墨基底（保留）

  • 问墨头部 + 朱砂"墨"印章头像
  • 气泡用户=墨块右对齐 · AI=宣纸卡左对齐
  • 研墨loader + 状态文案，AI 处理可见（交互原则 5.2）
  • 输入语音钮 + 朱砂上升发送键

纸间融合（新增）

  • 描金高亮答案中的关键信息用淡金荧光笔描出，一眼抓重点
  • 引用贴纸出处从虚线胶囊改为纸感实线贴纸，点按跳原文，长按对照预览
  • 印章按钮AI 主动建议"加入待办"——硬投影印章按钮，一步落地，不跳出对话
  • 题记头部下方一行小字：「基于你的笔记作答 · 引用均可溯源」
  • 纸签指令快捷气泡加墨线边框 + 偏移硬影，像纸间撕下的小签
