## 1. 设计语言（Design Language）

**双主题统摄全产品，结构恒一、仅换肤不换骨。**

- **日间 · 水墨 SUMI**：宣纸暖底、焦墨主字、朱砂印章强调、淡墨灰度。文化意象 = 水墨 / 题跋 / 印章 / 砚台。传达**质朴、文化、专注**。
- **夜间 · 极光 AURORA**：深空底、玻璃拟态卡片、雾白正文、青→紫→粉极光渐变。强调**沉浸、秩序、克制的高级感**。朱砂印章**夜间仍保留**，作为跨主题品牌符号。

**核心原则**
1. **结构>装饰**：先定布局骨架与信息层级，再谈视觉。
2. **令牌驱动**：一切颜色/圆角/阴影走 CSS 变量，禁止硬编码。
3. **主题一致**：夜版不是"换个深色"，而是按映射对照保留语义（见 §2.3）。
4. **可访问性内置**：对比度、触控目标、reduced-motion 从基线做起（§10）。

## 2. 主题系统（Theming）

### 2.1 切换机制
- 入口：设置页外观组 → **日/夜分段切换**（药丸容器「日·水墨」「夜·极光」两段，选中=深墨底）。
- 实现：`html[data-theme="night"]` 驱动 CSS 变量整套替换；也可叠加 `prefers-color-scheme` 跟随系统。
- 需持久化到本地（设置页存储）。

### 2.2 令牌分层
```css
:root { /* 日间值 */ }
[data-theme="night"] { /* 夜间覆盖 */ }
```
完整令牌见 `design-tokens.css` §1（色彩）、§2-§5（字体/圆角/间距/动效）。

### 2.3 昼夜映射（关键对照）
| 日间元素 | 夜间映射 | 备注 |
|---|---|---|
| 宣纸白背景 | 深空黑 + 极光光斑漂移 | 光斑 opacity .12–.18，**必须垫底**不遮卡片 |
| 实色卡片白 | 玻璃卡（`backdrop-filter:blur 8–10`） | 低端机降级为 92% 不透明深色 |
| 焦墨黑文字 | 雾白 | 保可读 |
| 朱砂红强调 | 极光三色渐变 | **印章除外**，印章保留朱砂 |
| 描金高亮 | 暖金光晕（降饱和） | 防夜间刺眼 |
| 墨晕入场 | 玻璃弹性入场 `bIn` | 动效对应 |
| 研墨 loader | 青色光环呼吸 `orbP` | — |

## 5. 半径 · 间距 · 阴影 · 边框

### 5.1 圆角
| 变量 | 值 | 用途 |
|---|---|---|
| `--r-page` | 20px | 页面大卡 |
| `--r-card` | 13px | 卷卡/浮层 |
| `--r-ico` | 8px | 图标容器/缩略图 |
| `--r-seal` | 7px | 印章 |
| `--r-fab` | 14px | 中央「+」 |
| `--r-pill` | 999px | 胶囊（按钮/分段/pills） |
| `--r-phone` | 46px | 手机外框 |

### 5.2 间距（8pt 体系）
`4 / 8 / 12 / 16 / 24 / 32 / 48 / 64`；页面左右留白 `--gutter:18px`；横向卷卡间距 `9px`。

### 5.3 阴影
```css
/* 卡片 */   0 6px 16px -10px rgba(28,27,24,.28)
/* 焦点卡 */  0 8px 20px -12px rgba(28,27,24,.30)
/* FAB */    0 8px 16px -6px rgba(28,27,24,.5)
/* 印章硬影 */ 2.5px 2.5px 0 rgba(184,58,42,.85)  /* 夜: rgba(0,0,0,.5) */
```

### 5.4 边框
- 卡片描边：日 `#CDC4AE` / 夜 `rgba(255,255,255,.14)`。
- 列表卡使用柔和投影而非硬边；浮起按钮用描边+上凸。

## 6. 布局规范（Layout）

### 6.1 手机框架（所有页面演示基准）
`352 × 726`、圆角 46、边框 9、刘海 88×22。

### 6.2 页面骨架（通用，自上而下保序）
```
状态栏(44) → 页面头/工具栏 → 内容区 → 底部操作/TabBar
```
- **状态栏**：今日为主页默认。「9:41」+ 信号 4 格 + 电池。
- **固定性约束**：状态栏与 TabBar **吸顶/吸底固定**；中层作为整体纵向滚动区；长卷内**横向滑动**。

### 6.3 首页「手帖」具体骨架
```
状态栏
头部：手帖 + 印章「记」+ 副标题「8月5日·今日已记3笔」｜ 搜索 + 视图切换
分类+排序：全部|工作|学习|生活  [⇅ 创建时间 ▾]
内容区·每日长卷（可纵滚）
  ● 今日 3条 → ◀ scard▸scard▸scard▸ ▶（横滑 snap）
  ● 昨日 2条
  ● 8月3日 4条
TabBar：手帖｜问墨｜+｜待办｜设置
```

### 6.4 视图体系（列表页保留三段切换）
- **列表（每日长卷）**：定稿主视图。
- **日历**：月历 + 墨点密度；点日展开当日长卷。
- **图库**：双栏瀑布流，适合图片多场景。

## 7. 图标库（Iconography）

- **共 43 枚**，统一 24 网格 / 1.75px 描边 / round 端点；日焦墨 `#1C1B18`、夜雾白 `#F2F4FF`；`stroke:currentColor` 由父级 `color` 换肤。
- 强调（选中/焦点）：日朱砂 `#B83A2A` / 夜极光青 `#8FE7F5`（走 CSS 变量）。
- `i-more`(···) 用 `fill:currentColor`，按 filled 图标处理。
- 分类分布：导航5 · 操作6 · 视图3 · 分类标签6 · 多媒体6 · 编辑状态3 · 设置页14。
- **导出资产**：`note-demo-icons.svg`（sprite）、`icons.json`（注册表）、`NoteIcon.tsx`（React）、`icons/`（单枚svg）、`icons-png-2x/`（48px day/night png）。

**应用位置**（部分）：底部导航(手帖/问墨/+/待办/设置)、头部(搜索/排序/视图三段)、分类(工作/学习/生活/想法/文件夹/标签)、设置页(外观/字体/隐私/锁定/语言/通知/存储/同步/账户/清除/备份/关于/帮助/退出)、多媒体卡(图片/录音/链接/附件)、编辑器(AI浮钮/发送/停止)。

## 9. 开发接入清单

1. **引入令牌**：入口 `@import 'design-tokens.css'`（或编译进工程）。杜绝硬编码色值/圆角。
2. **主题**：`html[data-theme]` 切换，日/夜两组变量；夜间光斑用 `body::before/after` 垫底 + `prefers-reduced-motion` 时停用。
3. **图标**：React 用 `NoteIcon.tsx`；原生用 sprite `<use>`；需要作图的用 `icons-png-2x/*.png`。
4. **字体**：引入 Google Fonts 五族（见 tokens 头部注释）或自托管。
5. **动效**：用登记关键帧名；统一时长变量 `--t-fast/normal/slow`，动画尽力用 `transform/opacity`。
6. **验收**：按 §10 清单走查。

## 10. 可视化验收清单（QA）

- [ ] **对比度**：正文 ≥4.5:1、大字 ≥3:1（日/夜均测）。
- [ ] **触控目标**：交互元素 ≥44px（FAB 40 例外，配放大热区）。
- [ ] **主题一致性**：同一元素日↔夜语义对应（见 §2.3），无"只有一个主题正常"。
- [ ] **夜版光斑**：3 枚光斑垫底不遮文字，低端机玻璃卡降级 92% 深色。
- [ ] **动效**：入场/声波/光环存在；`prefers-reduced-motion` 时全部取消。
- [ ] **图标**：同页同尺寸图标描边粗细视觉一致；无逐图标手改颜色。
- [ ] **布局**：状态栏/TabBar 固定，中层滚动不越界；长卷横滑无滚动条残留。
- [ ] **空/加载/边界**：空状态、加载占位、长标题截断、网络图片失败态齐备。

## 11. 新增 / 扩展流程（迭代基线）

> 任何新页面或视觉改动，遵循“**加令牌 → 建组件 → 四同步**”，保持单源不漂移。

1. **改令牌**：优先在 `design-tokens.css` 增加语义令牌，再在 `design-spec.json` 同步。
2. **新图标**：按 24/1.75/round 规范画好，追加进 `note-demo-icons.svg`，重跑导出脚本生成单文件/PNG/组件。
3. **新组件**：在本手册 §8 登记规格（结构/尺寸/状态/主题差异），并落一版可交互原型。
4. **四同步**：手册 `.md`、令牌 `.css`、规范 `.json`、图标/组件导出物**四者同步更新**，改一处核对其余。
5. **通知**：设计/开发改动走版本化（如本手册 v1.0 → v1.1），附变更说明。
