## 一、本次范围与页面结构

**范围**：仅 **笔记列表页（手帖，首页默认）** 一屏。采用「每日长卷」布局（定稿），创建入口统一收进底部导航中央「+」。

**页面自上而下完整结构**（必须保序）：

```
┌──────────────────────────────────────┐
│ [状态栏]           9:41 · 信号 · 电池    │ ← 固定
├──────────────────────────────────────┤
│ [头部区域 nhead]                        │
│   「手帖」+ 印章「记」   │ 搜索钮 + 视图切换 │
│   副标题「8月5日 · 今日已记 3 笔」       │
├──────────────────────────────────────┤
│ [分类筛选 pills + 排序]                  │
│  全部│工作│学习│生活   [⇅ 创建时间 ▾]    │
├──────────────────────────────────────┤
│ [内容区 · 每日长卷]   （可纵向滚动）       │
│   ● 今日   3条                     │
│   ◀ scard ▸ scard ▸ scard ▸ scard ▸  │ ← 横向滑动
│   ● 昨日   2条                     │
│   ● 8月3日  4条                     │
├──────────────────────────────────────┤
│ [底部导航 TabBar]  手帖│问墨│+│待办│设置   │ ← 固定
└──────────────────────────────────────┘
```

**固定性约束**：状态栏与底部 TabBar **吸顶/吸底固定**；中间「头部 + pills + 每日长卷」作为整体**纵向滚动区**。滚动时长卷内部再**横向下滑展开**。

## 三、设计语言与主题系统

### 3.1 双主题语言（沿用全局）
- **日间 · 水墨 SUMI**：宣纸暖底 `#F6F1E6`、焦墨主字 `#1C1B18`、朱砂强调 `#B83A2A`、淡墨灰次级 `#8A8272`。
- **夜间 · 极光 AURORA**：深空底 `#0A0D1F`、玻璃卡片 `rgba(255,255,255,.07)`、雾白正文 `#F2F4FF`、极光渐变 `linear-gradient(120deg,#4FD8EB,#8B7CFF 55%,#FF7AD9)`。**印章例外，夜间仍保留朱砂红**作品牌符号。

### 3.2 主题切换（原型已带，可直接沿用）
- 原型顶部提供「日间·水墨 / 夜间·极光」切换（`data-theme` 属性驱动），一套令牌双套值。
- 夜间背景伴随三枚**极光光斑**（青/紫/粉，`opacity .16` + `filter:blur(90px)` + 慢速漂移动画），**必须垫底（z-index 底层）**，不遮挡卡片与文字。
- 实现建议：`html[data-theme="night"]` 切换 CSS 变量；如需跟随系统，再叠加 `prefers-color-scheme` / 设置页手动分段。

## 六、分类筛选（pills）+ 排序

### 6.1 布局
- 该行 = **横向滚动分类 pills（左，弹性占满）+ 排序按钮（右，固定）**，左右同高、同 `padding 13/18/10`。
- 同行排列，避免多占一行。

### 6.2 分类 pills
- 横向滑动、隐藏滚动条；胶囊圆角 99、`11.5px`、默认字重 500、描边 `--pill-border`。
- **预设分类（已去除「收藏夹」）**：全部 / 工作 / 学习 / 生活。
- **选中态（视觉锚点）**：实心填充 + **不规则圆角 `999px 12px 999px 14px`**；日间=焦墨底白字（字重700），夜间=极光渐变底深字。
- 交互：点选即过滤内容区卷卡（见第十一节行为 #B）。

### 6.3 排序按钮 + 下拉菜单
- **排序钮**：右侧胶囊（圆角99、`11px`、描边 `--pill-border`），内容 = 排序图标（list 型 12px）+ 当前排序名（「创建时间」/「标题」）+ 展开箭头 `▸`；悬浮描边变朱砂（夜青色）。
- **点击展开下拉**：胶囊下方右对齐浮层（`128px` 宽、圆角12、卡片底 + 描边 + 阴影，夜间玻璃化），含两选项：
  - **创建时间**（默认，选中态朱砂 + 左侧实心圆点）
  - **标题**
- 点选项即应用排序并收起；点页面其他处关闭下拉。
- 交互：见第十一节行为 #J。

### 6.4 排序语义（务必与开发对齐）
- 每日长卷是**按日分组**结构（今日→昨日→8月3日）。因此：
  - **「创建时间」** = 默认序：先按日期降序（日组顺序），组内按时间先后；即**恢复 DOM 原始顺序**。
  - **「标题」** = 组内重排：不改变日期分组，仅在各「日」的横向卷内按标题字母序（`localeCompare('zh-Hans-CN')`）重排卡。
- 若产品后续需要**跨日全局排序**，将突破「每日长卷」分组语义，需另行评审（列入待确认 #11）。

## 七、内容区 · 每日长卷（核心）

### 7.1 日期题头（dayhd）
- 左：**菱形节点** 7×7、45° 旋转、圆角 1.5；日=朱砂 `--acc`，夜=极光渐变。
- 日期文字 `Noto Serif SC 900 / 12px`，字距 .14em；其后计数小字 `9px` 灰。
- 「更多 ⌄」右对齐、朱砂色（夜 #8FE7F5）、可点。
- **过期日组**整体降透明度（如 8月3日 `opacity .72`）表时间衰减，菱形淡灰。

### 7.2 横向滚动区（hscroll）
- `display:flex; gap:9px; overflow-x:auto; scroll-snap-type:x mandatory`；隐藏滚动条。
- 每张卷卡 `scroll-snap-align:start`。

### 7.3 单张卷卡（scard）
- 尺寸 **150px 宽（flex:0 0 150px）**、min-height 112px、圆角 13、内边 `11px 12px 11px 14px`。
- **左侧朱砂竖条** 2.5px 宽、top/bottom 10px、`opacity .55`（夜=极光渐变 .7）：表「朱砂封印」。
- 三层信息：h5 标题（宋体900 11.5px，2行截断）`→` p 摘要（9px，2行截断）`→` sm 元数据行（`margin-top:auto` 贴底）。

```
┌────────────────────┐
│▎ 季度评审会笔记       │ ← h5 宋体 900
│  确认 9/15 上线…      │ ← p 摘要 2 行截断
│  [工作]  10:24         │ ← sm：pill-mini 标签 + 时间
└────────────────────┘
```

- sm 行内 pill-mini：分类小药丸（朱砂淡底 10% + 朱砂字；夜=青淡底 + 青字）。

## 九、底部导航 TabBar

- 五 Tab：**手帖（列表） / 问墨（AI） / 中央「+」（创作入口） / 待办 / 设置**；样式自适应高（图标24px + 文字9px）。
- 容器：`padding 8px 14px 16px`、底 `--tab-bg` + `backdrop-filter:blur(14px)`、`border-top 1px var(--line)`。
- 各 Tab 文字 9px；**当前页（手帖）**：朱砂色（夜 #8FE7F5）+ 顶部 2px 小竖条指示（夜渐变）。
- **中央「+」FAB**（要点）：
  - 40×40、圆角14、日间焦墨底 `#1C1B18`、夜间**极光渐变**底深色图标。
  - **向上凸出** `margin-top:-24px`，需 TabBar 容器允许溢出（`clipsContent:false` 等价处理）。
  - 阴影 `0 8px 16px -6px rgba(28,27,24,.5)`；点按触发**外扩光环**动画（`ringp` 2.2s）。

## 十、空状态与降级

- 当分类筛选后无匹配，显示**空状态 ghost**：上 4×4px 圆点（左右带两颗小影点），下文案「还没有笔记，点击下方 + 开始记录」`9.5px` 灰、字距 .12em。
- 视图降级：三段视图切换的「日历 / 图库」为预告入口，本轮**每日长卷为唯一定稿视图**，另两段仅高亮切换、内容仍以长卷展示（或显示建设中占位）。

```css
  --shadow-card:0 6px 16px -10px rgba(28,27,24,.28);
  --shadow-focus:0 8px 20px -12px rgba(28,27,24,.30);

[data-theme="night"]{
  --pbg:#0A0D1F; --card:rgba(255,255,255,.07); --pfg:#F2F4FF;
  --acc:#FF7AD9; --mut:#7F89B4; --line:rgba(255,255,255,.14);

  --pill-border:rgba(255,255,255,.14); --pill-txt:#C7CEEC;
  --shadow-card:0 6px 16px -8px rgba(0,0,0,.5);
  --shadow-focus:0 10px 24px -10px rgba(0,0,0,.55);
}
```

## 十四、待开发确认 / 评审事项

1. **滚动容器模型**：状态栏 + TabBar 固定，中层（头部+pills+长卷）纵向滚动、长卷内横向滚动——确认用单一 `overflow-y` 外层 + 内层 `overflow-x`，避免嵌套滚动冲突。
2. **scroll-snap**：`x mandatory` 在低端 WebView 的兼容与降级策略（不支持时退化为普通横向滚动）。
3. **日期分组数据模型**：按「日」分组返回卷卡数组（`day → scard[]`），每张卡需带 `type`（text/voice/img/link）+ `category`（work/study/life）+ `time` 字段供过滤/排序/渲染。**注意**：分类筛选已不含「收藏夹」，`isFav`（若保留）仅作文卡内标记、不作为筛选维度。
4. **分类过滤实现位置**：建议在前端过滤（数据量小）或后端 SQL（量大）——需开发定数据规模上限。
5. **「更多」与视图切换**：日期「更多」展开的承载（跳转详情 vs 就地展开）语义待产品确认；日历/图库视图本轮是否仅占位高亮。
6. **搜索入口**：搜索钮本轮是否仅占位，进入搜索结果页是否复用已有搜索能力。
7. **相对时间「今日已记 3 笔」**：本地时钟 + 计数刷新策略（进入前台时重算）。
8. **图片缩略图**：48×48 缩略图加载中/失败态（占位底色用金色渐变）。
9. **`prefers-reduced-motion`**：入场/声波/光环动画需提供静态降级。
10. **凸起 FAB**：TabBar 容器溢出裁剪需关闭，确保负 margin 按钮完整显示 + 光影正常。
11. **排序语义（新增）**：默认「创建时间」= 恢复按日序 DOM 原序；「标题」= **仅在各日组内**按标题重排、不拆分日期分组。若需跨日全局排序（突破每日长卷分组语义）须另行评审。下拉浮层需打点、支持点击外部关闭。
