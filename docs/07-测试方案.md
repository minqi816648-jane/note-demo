# note-demo 测试方案

## 1. 测试概述

### 1.1 测试目标

确保 note-demo 应用的功能正确性、性能达标、数据安全性和用户体验质量。

### 1.2 测试范围

- 单元测试：核心逻辑、数据层、AI 服务封装
- 集成测试：模块间交互、数据库操作、AI 调用
- UI 测试：界面交互、导航流程、组件渲染
- 性能测试：启动时间、列表滚动、内存占用
- 安全测试：数据加密、权限控制、敏感信息保护
- 兼容性测试：不同 Android 版本、屏幕尺寸

### 1.3 测试工具链

| 层级 | 工具 | 用途 |
|------|------|------|
| 单元测试 | Jest | 逻辑测试 |
| 组件测试 | React Native Testing Library | 组件渲染测试 |
| E2E 测试 | Detox | 端到端测试 |

### 3.2 关键测试用例

#### 3.2.1 笔记服务测试

```typescript
describe("NoteService", () => {
  describe("createNote", () => {
    it("should create a note with valid data", async () => {
      const note = await noteService.createNote({
        title: "测试笔记",
        content: "<p>内容</p>",
        category_id: "cat_work"
      });
      expect(note.id).toBeDefined();
      expect(note.title).toBe("测试笔记");
      expect(note.created_at).toBeDefined();
    });

    it("should throw error when title is empty", async () => {
      await expect(noteService.createNote({ title: "" }))
        .rejects.toThrow("title is required");
    });
  });

  describe("deleteNote", () => {
    it("should soft delete a note", async () => {
      await noteService.deleteNote("note_001");
      const note = await noteService.getNote("note_001");
      expect(note.deleted_at).toBeDefined();
    });

    it("should restore a deleted note", async () => {
      await noteService.restoreNote("note_001");
      const note = await noteService.getNote("note_001");
      expect(note.deleted_at).toBeNull();
    });
  });
});
```


#### 3.2.2 AI 服务测试

```typescript
describe("AIService", () => {
  describe("classifyNote", () => {
    it("should classify note content correctly", async () => {
      const result = await aiService.classifyNote("完成项目报告");
      expect(result.category_id).toBe("cat_work");
      expect(result.tags.length).toBeGreaterThan(0);
      expect(result.is_todo).toBe(true);
    });

    it("should handle API failure gracefully", async () => {
      mockApi.failNextRequest();
      const result = await aiService.classifyNote("测试内容");
      expect(result.category_id).toBe("cat_idea"); // 降级默认
    });
  });

  describe("sendMessage", () => {
    it("should stream response chunks", async () => {
      const chunks = [];
      for await (const chunk of aiService.sendMessage("conv_001", "你好")) {
        chunks.push(chunk);
      }
      expect(chunks.length).toBeGreaterThan(0);
      expect(chunks[chunks.length-1].type).toBe("done");
    });
  });
});
```
