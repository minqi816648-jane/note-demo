# note-demo 开发版本计划

## 1. 项目概述

### 1.1 项目目标

开发一款 AI 智能笔记助手移动应用（Android 优先），核心功能包括：

- 笔记管理（文字、图片、链接、语音、附件）
- AI 自动分类、打标签、智能问答
- 待办事项管理
- 本地优先存储 + 可选云同步
- 语义搜索 + OCR 搜索

### 1.2 技术栈

| 层级 | 技术 |
|------|------|
| 前端 | React Native + Expo |
| 状态管理 | Zustand |
| 本地数据库 | SQLite (expo-sqlite) + SQLCipher |
| 导航 | expo-router |
| 富文本 | react-native-pell-rich-editor |
| AI | 通义千问 / DeepSeek |
| OCR | 百度 OCR |
| 语音 | 讯飞实时语音 |

## 6. 风险与应对

| 风险 | 影响 | 概率 | 应对措施 |
|------|------|------|----------|
| AI API 不稳定 | 功能不可用 | 中 | 多 Provider 切换+本地降级 |
| 富文本编辑器兼容性 | 编辑体验差 | 高 | 充分测试+自定义渲染兜底 |
| 语音识别准确率 | 转写质量差 | 中 | 提供手动编辑+多语言支持 |
| 开发进度延期 | 交付延迟 | 中 | 敏捷迭代+功能优先级调整 |
| 存储空间不足 | 数据丢失 | 低 | 自动清理+备份提示 |
| 设备兼容性问题 | 部分设备异常 | 中 | 广泛测试+错误上报 |
